# crocs-facts

A fun, interactive web page to learn about crocodiles, designed with a wildlife theme.

## Features
- Wildlife-inspired background and visuals
- Crocodile image and themed styling
- Animated fact display
- Show random fact, next fact, or all facts
- Fact counter and interactive controls

## How to Use
1. Open `index.html` in your browser.
2. Click the buttons to explore crocodile facts.
